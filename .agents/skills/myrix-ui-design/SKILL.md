# Myrix UI 设计

## 何时使用

新增或改动 `apps/novel-web` 的界面、文案、排版、交互与状态展示时使用。业务对象与权限用 [myrix-business](../../../.agents/skills/myrix-business/SKILL.md)，模块边界与门禁用 [myrix-development](../../../.agents/skills/myrix-development/SKILL.md)，本 skill 只管“作者看到什么、怎么交互、如何被验证”。

**权威标准**是 [工作台 UI 设计标准](../../../docs/development/ui-design.md)；本 skill 是执行清单。标准里的“规范”与“实现状态”必须分开读，任何“已实现”结论都要有源码或测试证据。

## 先读

[AGENTS.md](../../../AGENTS.md)、[UI 设计标准](../../../docs/development/ui-design.md)、[novel-web 实现](../../../docs/implementation/novel-web.md)、[业务说明](../../../docs/business.md) 与 [验证方法](../../../docs/testing/acceptance.md)。先看 `git status` 与工作区现有改动，不覆盖他人未完成的工作。

## 设计路径

1. **先认任务与区**：书架（唯一入口）→ 书内四区（大纲 / 章节 / 设定 / 创作助手）。每个改动回答“服务作者的哪个任务、省掉哪几步”，不为了视觉整齐牺牲写作流程。
2. **定信息层级**：首屏必须回答“我在写哪一章、写了多少、存了吗、下一步做什么”；其余按“一次点击 / 事件驱动 / 可达但不常驻”分层。同一事实只留一个权威位置（草稿状态在文档头，命令状态在气泡内，回合状态在协作区头部）。
3. **守住状态词表**：草稿、版本、命令、回合、会话五种状态不得共用容器或互相冒充。`202 queued` 只是入队；回合终态与持久业务数据确认前，**不得说“已保存”**。
4. **保护文本事实**：正文永远是纯文本、载入/导出逐字可逆（连续空格、空行、行首尾空格）。章节/大纲/设定保持纯文本，不因要排版就 Markdown 化或 HTML 化。空内容也必须可进编辑、可保存。
5. **只读展示走安全允许集**：可以渲染标题/列表/引用/代码围栏/GFM 表格；禁止 `rehype-raw` 与任何 `dangerouslySetInnerHTML`；原始 HTML 只作文本显示；图片一律不加载、只出文字占位；链接只放行 `http(s)://`、`mailto:`、`#锚点`，其余降级为文本。既有实现见 [ReadingContent.tsx](../../../apps/novel-web/src/components/ReadingContent.tsx)，不要绕过它的白名单。
6. **阅读优先、编辑显式**：默认阅读排版，用户显式动作后进入编辑器，载入源是已存储原文。任何对象都要能从阅读态进编辑态。
7. **改目标才能改内容**：当前选中的章节/大纲/设定就是默认修改目标，界面用 target chip 常驻显示。发送时只追加 identifier + title + dirty，**绝不附带正文**；目标在发送瞬间冻结（含新会话等待期间），在途回合不因切换选中而改变。Agent 必须先用现有工具读最新已保存内容，再按 `expectedVersion` CAS 保存。
8. **令牌与尺度**：颜色、圆角、阴影走 `:root` 变量，不硬编码；次要信息 ≥ 12px，常用可点击控件桌面 ≥ 36px、移动 ≥ 44px。正文 ≥ 15px、行高 ≥ 1.9。
9. **隐藏不卸载**：≤900px 切栏与专注模式只改可见性，不卸载编辑器、草稿或事件流；移动端“目录→返回内容”要带着内容回来。
10. **键盘与安全**：`Ctrl/Cmd+S` 等同保存，输入法组合中不触发；`Enter` 发送 / `Shift+Enter` 换行并防双发；失败保留输入。CAS 写入带 `expectedVersion`，409 逐字保留草稿并给显式裁决路径；不自动持久化草稿、不自动发送未保存正文。

## 硬边界

- 不修改 `vendor/deepseek-harness`；DSH 侧定制只走 Cordis 插件 / bundle。
- 模型链路只用 **Responses**；本项目禁止 `chat/completions`，界面与装配不得保留兼容入口、隐式转换或失败回退。
- 当前 **Cell** 不启用 skill 插件或 `skill` 工具；本 skill 不进入 Cell，也不作为扩大白名单的理由。六个小说工具不变，界面不得新增绕过工具边界的写路径。
- 归档（可恢复）≠ 撤权（不可恢复）≠ 删除内容；身份/作品/版本字段来自服务端，界面不得提交或展示可编辑的身份字段。
- 调用真实模型会计费，须操作者明确授权；线上部署、重启、迁移与凭据轮换须单独确认范围。

## 门禁与证据

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build:web
```

界面改动必须带语义回归（安全渲染、纯文本往返、CAS/冲突保留、草稿保留、IME、移动切栏不丢草稿），并且不能只靠 jsdom：在真实浏览器做约 1440px 桌面与约 390px 移动检查，留存截图到被忽略的运行目录。报告按 [验证方法](../../../docs/testing/acceptance.md) 分层写清“执行/未执行/跳过”：组件测试不等于浏览器验收，本地浏览器不等于线上模型闭环，历史结果不证明当前提交。

交付列出改动文件、实际命令与结果、截图结论、未验证边界与剩余风险；未实现的规范明确写“未实现”，不把目标写成现状。
