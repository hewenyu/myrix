## 唯一入口与事实来源

[文档索引](<README.md>)是唯一项目说明入口，根 [README](<../README.md>)保留定位、演示、快速启动和导航。业务、开发、接口、部署、测试、ADR 和复盘统一在本目录；源码旁不再复制完整说明。机器发现所需的 [AGENTS](<../AGENTS.md>)、项目 skills、许可证与 NOTICE 保留在各自标准位置，不属于散落的业务文档。

修改文档时以源码、配置校验、测试脚本为依据。标注“当前实现”“历史记录”“待验收”，不要用旧测试数量、作者个人环境或一次供应商探测证明当前版本上线。ADR 保留决策理由，废弃设计注明被哪个决策替代，不删除仍有解释价值的安全决策。

## 公开与私有边界

**可以公开**：自部署步骤、通用拓扑、端口、环境变量名、API、测试用固定夹具、维护者明确授权的演示 URL。共享体验凭据仅在维护者明确授权创建/公开专用账号后发布，必须验证实际身份与登录；不能自动从 `.env`、realm 导入或备份中挑选既有密码。公开镜像分发仓库与上游来源属于必要供应链标识，保留正确值，不把它们与秘密混为一谈。

**不得公开**：上游 API key、Cell token、签名私钥、OIDC client secret、真实数据库连接串、主机 SSH 信息、Keycloak bootstrap 管理口令、Cookie/CSRF/浏览器 storageState、未经清理的日志或业务稿件。展示日志时只留错误类型、匿名标识、状态码与时间，不整包上传截图、抓包或数据库备份。

根 [Git 忽略规则](<../.gitignore>)覆盖本地文档、部署 skill、既有 agent 草稿、运行数据、环境文件；[Docker 忽略规则](<../.dockerignore>)单独排除这些内容，**Docker 不读取 gitignore**。生成的 VPS 配置继续由[部署忽略规则](<../deploy/vps/.gitignore>)保护。本地目录建议 `0700`、文件 `0600`；Git 忽略不等于磁盘加密，不要把它当成访问控制。

## 提交前核对

```bash
git diff --check
git status --short
git check-ignore docs/local/README.md .agents/skills/myrix-deploy/SKILL.md
# 应无输出；--exclude-standard 不用于此处，目的是找已被跟踪的私有文件
git ls-files docs/local .agents/skills/myrix-deploy .team
```

此外检查公开 Markdown 本地链接存在、导航覆盖新增文档、skills 的名称/描述有效、示例不使用真实供应商或环境凭据。迁移文档时同步测试中读取文档的路径和错误提示，不能只修 README。

**历史限制**：gitignore 不会取消已跟踪文件，也不会清理历史提交、远端、fork 或缓存。本次仅整理当前工作树，未改写 Git 历史。若发现曾提交的真实秘密，先撤销/轮换，再由维护者批准协调历史清理；将旧文件本地归档不等于撤回已经公开的密钥。本次不自动推送、不强推、不删除既有部署或数据库。
