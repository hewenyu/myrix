# ADR 0025：首版小说部署的显式能力策略发布

- 状态：已采用，真实 Cell 消费链路仍须单独验收
- 日期：2026-10-01

## 背景

有限期策略桥只解决执行点如何接收权威快照。若生产 BFF 仍不传策略，工具守卫应继续默认拒绝，不能把取消守卫当作整合完成。

## 决策

[持久化 BFF 装配](<../../apps/bff/src/production.ts>) 显式向绑定快照生产者提供首版小说能力策略：

- `rev: 1`，独立于会话撤权版本。以后变更部署的能力集合必须增加策略版本。
- `ttlMs: 10000`，由 Cell 按策略桥的有限期规则消费；不是无限有效的进程全局 allow 开关。
- 仅 [小说协议](<../../plugins/myrix-novel/src/protocol.ts>) 定义的六个 `NOVEL_TOOLS`；不是任意 DSH 工具。

这是小说产品部署已选择的能力白名单，不是某个用户或会话已经获得授权的证明。内部端点仍只接受登记的 Cell 凭据，路径 Cell 必须相符，租户由凭据确定。绑定快照只包含活动租户、有效成员、归属作品且有效的绑定；调用仍需六字段主体、实时绑定/成员检查、预设交集和 CAS。

其他调用方若不显式传第三参数，快照中没有策略，执行点继续拒绝。无有效策略、无法刷新、租约到期、版本回退均不允许借此静态白名单绕过。

## 可观测原因与验证

- 无 Cell 凭据：401；持另一 Cell 凭据请求错误路径：403；不会回传凭据。
- 策略缺失/陈旧/已过期：由策略守卫保留可读拒绝原因，而不是启用全部工具。
- [真实 LOGIN 装配集成测试](<../../apps/bff/tests/production.integration.test.ts>) 验证正式工厂确实下发有限期六工具策略和当前绑定，而不只是对生产者函数单测。
- Cordis 必须以真实依赖关系协调快照服务的生产者/消费者；配置行顺序不是服务已就绪的证明。不得通过关闭 `requirePolicy` 让正式 Cell 的 smoke 通过。

本 ADR 不增加浏览器策略编辑 API，不让 Cell 保存或推导策略，也不改变内容单属主、无管理员旁路的规则。
