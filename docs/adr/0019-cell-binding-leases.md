# ADR 0019：Cell 主体活性采用短租约，资源操作仍查权威数据库

状态：接受；与运行时租约插件的完整装配待验收。

## 决策

内部作品服务提供 `GET /internal/v1/cells/:cellId/bindings`。服务端用 Cell bearer 凭据解析租户及 Cell，不接受调用者指定用户身份或其他租户。路径 Cell 不匹配返回 403，未认证返回 401，未装配快照读取器返回 503。响应禁止缓存，只含 `cellId`、`tenantId` 和 `{sid,tid,sub,wid,preset,rev}` 数组，不含作品正文或凭据。

快照查询运行在非 owner 的事务内租户 RLS 上。仅考虑当前 Cell 的 creating/active 绑定、active 租户、active 且与绑定同所有者的作品；成员和会话准入复用纯 `authorizePlatform` 的 `sessions:read` 判定。成员停用、会话撤销、作品删除后的新快照不再包含该主体。超过 10,000 条候选绑定明确失败，不返回容易被误认为完整的截断快照。

Cell 只能把快照作为有限寿命、失败即清空的同步活性租约，不能把它当永久授权。创建绑定与首次挂载之间须等待新快照，不能以“尚未同步”为理由默认放行。租约机制不能替代每次工具/模型操作对数据库中当前绑定、成员、租户和版本的核验；新旧快照传播窗口内仍由这些资源侧检查阻止已撤权的业务访问。

## 作品删除并发

小说工具入口在同一事务内对绑定、成员、租户和作品持有 SHARE 行锁，直至仓储读写完成。作品必须仍为 active 且属于绑定所有者。由此软删除不能跨过已核验的工具写事务，删除先提交则后续工具拒绝；管理员仍无正文读取特权。

## 验证范围

BFF PostgreSQL 集成测试新增 Cell 凭据/路径错配、完整快照字段、删除后快照移除和工具拒绝；已有阻塞保存用例增加作品软删除的 `55P03` 锁超时断言。测试使用独立的真实 LOGIN 非 owner 角色，不通过 owner 连接的角色切换假装隔离。运行命令及结果由集成验收记录维护；本 ADR 本身不声称端到端已完成。
